# SecurePass

SecurePass is a premium frontend-only password generator built with React, Vite, Tailwind CSS, Framer Motion, and React Router.

## Features

- Secure local password generation using `crypto.getRandomValues()`
- Multiple password categories including universal, email, banking, PIN, Wi-Fi, and developer use cases
- Password history and favorites stored locally with `localStorage`
- Responsive orange-red cybersecurity dashboard UI
- PWA support for installable offline use

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- React Router

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
